# Leonardo KeycapRio
Leonardo KeycapRio is a custom made, single pcb, tented unibody MX keyboard. It uses squiggles on the pcb to allow bending the pcb without breaking it.

It consists of:
- rp2040 pro micro
- A single pcb
- Smd diodes
- MX Hotswap sockets

Its running my own firmware, zigmkay, which can be found here: [https://github.com/zigmkay/zigmkay_firmware](https://github.com/zigmkay/zigmkay_firmware/)

All files needed are in this repo except the onshape document which is found online here: [Onshape document for the tenting](https://cad.onshape.com/documents/2fc5b31bd095c1f6dcf1e4f8/w/506d41ccf5be44630b84bc55/e/45017851df1b112820f21494)
